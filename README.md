# 레테 처방전 / Lethe Formula

바닷가 도시 **시에스타**의 작은 연구소 — 아이젠비더 연구소에서 보내는 **30일간의 인턴십**.
숙취 해소제 '테라1004'를 만드는 이곳에서, 당신은 매일 어디로 갈지 고르고, 사람들과 이야기를 나누고, 업무를 돕는다.
누구를 자주 찾아가고 어떤 선택을 하느냐에 따라, 한 달 뒤의 끝은 저마다 달라진다.

*명일방주(Arknights) 세계관을 빌린 2차 창작 비주얼 노벨 · 일상 시뮬레이션입니다.*

---

## 어떤 게임인가요

- **장소를 고르는 하루** — 실험실, 진료실, 안전관리실, 물류창고, 소장실. 매일 정해진 행동 안에서 누구를 만나고 무엇을 할지 정합니다.
- **사람과의 거리** — 자주 찾아가고, 잘 듣고, 어떻게 답하느냐에 따라 관계가 쌓이거나 멀어집니다.
- **여러 갈래의 결말** — 업무·관계·조사, 그리고 몇 번의 중요한 선택이 모여 서로 다른 엔딩으로 이어집니다.
- **다시 플레이** — 한 번의 플레이는 30일로 끝나지만, 다음 플레이에는 지난 회차의 흔적이 조용히 남습니다.

스포일러 없이 말할 수 있는 건 여기까지. 나머지는 직접 겪어 보세요.

## 등장인물

| 인물 | 자리 | 첫인상 |
|---|---|---|
| **벨가** | 연구소 소장 | 둥글게 말린 뿔, 다정한 말투. 웃음 끝이 조금 길다. |
| **베스프레델** | 상주 의사 | 무뚝뚝하고 말수가 적다. 아침을 거르면 하루 종일 까다롭다. |
| **이시리얼** | 안전관리 담당 | 정중한 존댓말과, 자기 얼굴에 대한 변함없는 자부심. |
| **로모모** | 실험실 연구원 | 엉뚱하고 솔직하다. 기분은 꼬리가 먼저 말한다. |
| **덱켄** | 물류창고 | 과묵하고 짧게 말한다. 빵을 반으로 나눠 준다. |

## 플레이 방법

브라우저에서 접속해 바로 플레이할 수 있습니다. 설치도, 가입도 필요 없어요.

1. 타이틀에서 **새 게임**을 눌러 시작합니다.
2. 간단한 면접(이름·지원 동기·관심 분야)을 거칩니다.
3. 하루하루 장소와 행동을 골라 30일을 보내고, 엔딩에 도달합니다.

- **진행**: 화면을 클릭하거나 `Space` · `Enter`
- **선택지**: 숫자키 또는 클릭
- **저장**: 자동 저장 (브라우저에 보관되며, 언제든 이어 할 수 있어요)
- 한 번 본 엔딩은 **엔딩 수집** 화면에서 다시 읽을 수 있습니다. 새로 플레이하면 지난 회차의 흔적이 조용히 남습니다.
